# Travel Trucks 🚐

## Project Description

**Travel Trucks** is a web application for searching and filtering campers and vans for travel. Users can choose vehicles by location, body type, and available amenities (AC, kitchen, TV, bathroom, etc.). The project focuses on a user-friendly interface and persistent filter storage.

🔗 Demo: https://travel-trucks-opal-omega.vercel.app

---

## Key Features

- 🔍 Camper filtering by location
- ✅ Amenities selection (AC, Kitchen, TV, Bathroom)
- 🚚 Vehicle type filtering (Van, Fully Integrated, Alcove)
- 💾 Filter persistence using `localStorage`
- ⚡ Fast performance powered by Next.js
- 📱 Responsive design

---

## Technologies

- Next.js
- React
- TypeScript
- Zustand (state management with persist)
- CSS Modules
- Vercel (deployment)

## Installation Guide

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Mykhailenko-Oleksandr/travel-trucks.git
```

### 2️⃣ Navigate to the project directory

```bash
cd travel-trucks
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Run the development server

```bash
npm run dev
```

The project will be available at:
👉 http://localhost:3000

## Usage

- Enter a city in the Location field
- Select the required amenities
- Choose the vehicle type
- Click Search
- The selected filters will be saved automatically and restored after page reload
